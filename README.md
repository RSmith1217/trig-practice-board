# Exact Trig Practice Board

Standalone classroom practice for Precalculus Honors, with 11 skill categories, exact answers, optional unit-circle diagrams, full-screen presentation, and keyboard controls.

## Run

Open `index.html` in a modern browser. No build step, external scripts, account, or backend is required by the app.

## Publish with GitHub Pages

In repository Settings → Pages, select Deploy from a branch, then `main` and `/ (root)`. Use the URL GitHub returns for the link from dydxmath.com. The app already links back to https://dydxmath.com/.

## Controls

- Choose a skill and problem, then reveal the answer.
- Show diagram provides an optional visual explanation.
- Space: reveal/hide answer; left/right arrows: previous/next; R: random; D: diagram. Keyboard shortcuts apply when a form control or button does not have focus.
- Random selection cycles through a shuffled bank before starting a new cycle.

## Source

All markup, styles, problem banks, exact-value formatting, and diagrams are in `index.html`. No student data is collected or stored.
